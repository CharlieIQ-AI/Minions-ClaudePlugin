---
description: Report Minions usage and analytics numbers
argument-hint: "[report] [range]"
---
Use the Minions skill to answer a reporting question without changing anything. Parse `$ARGUMENTS`: a report name (usage, weekly, leaderboard, work themes, creation paths, AI cost, compute costs, first mile, task creation) and an optional range, passed in the parameters that report's tool takes (the Minions skill lists them per tool; work themes takes none); with no report named, read the Usage report for the last 30 days. Report the figures the tool returns with its window and definitions, drill into a team, person or organization only when asked, and relay a permission refusal as the answer. Keep the report read-only.
